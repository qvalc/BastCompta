Présentation

1. Qu’est-ce que BastCompta ?

BastCompta est une application de gestion conçue principalement pour les indépendants, les indépendants complémentaires, les petites entreprises et les sociétés qui souhaitent gérer leur activité de manière simple, moderne et centralisée. L’objectif est de regrouper au même endroit la gestion commerciale, le suivi comptable, les clients, les devis, les factures, les tarifs, le Mode Terrain, les sauvegardes ainsi que plusieurs outils d’aide à la comptabilité. BastCompta est développé progressivement afin d’ajouter régulièrement de nouvelles fonctionnalités.

2. À qui s’adresse BastCompta ?

BastCompta convient notamment : - aux indépendants complémentaires ; - aux indépendants à titre principal ; - aux artisans ; - aux entreprises de construction ; - aux paysagistes ; - aux commerces ; - aux PME ; - à toute personne souhaitant simplifier sa gestion quotidienne. Le logiciel est pensé pour rester simple d’utilisation, même sans connaissances approfondies en comptabilité.

3. Que permet BastCompta ?

Selon les modules activés, BastCompta permet notamment de : - gérer les clients ; - créer des devis ; - créer des factures ; - gérer une bibliothèque de tarifs réutilisable ; - préparer la comptabilité ; - préparer les déclarations TVA ; - préparer l’IPP ; - suivre les achats et investissements ; - gérer les stocks ; - enregistrer les kilomètres professionnels ; - utiliser le Mode Terrain sur chantier ; - synchroniser les données avec Google Drive ; - réaliser des sauvegardes ZIP. De nouvelles fonctionnalités sont ajoutées au fil des mises à jour.

4. BastCompta remplace-t-il un comptable ?

Non. BastCompta est un outil d’aide à la gestion. Il facilite la préparation des données comptables, des déclarations TVA et du résumé IPP, mais il ne remplace ni un comptable, ni un expert-comptable. Les données préparées peuvent être utilisées comme support de travail ou transmises à votre comptable.

5. Sur quels appareils puis-je utiliser BastCompta ?

BastCompta fonctionne directement depuis votre navigateur. Vous pouvez l’utiliser sur : - ordinateur Windows ; - ordinateur Mac ; - ordinateur Linux ; - tablette ; - smartphone. Certaines fonctionnalités, comme le Mode Terrain, sont particulièrement adaptées à une utilisation mobile.

6. Quelle est la différence entre BastCompta et le Mode Terrain ?

Le Mode Terrain est un module complémentaire destiné aux interventions sur chantier. Il permet notamment de : - sélectionner un client ; - créer rapidement un devis ; - utiliser la bibliothèque de tarifs ; - ajouter des remarques ; - prendre des photos ; - enregistrer un brouillon. Une fois de retour au bureau, les brouillons peuvent être repris dans BastCompta afin de finaliser et envoyer le devis. Le Mode Terrain ne remplace donc pas BastCompta : il le complète en facilitant le travail directement sur le terrain.

Premiers pas et compte

7. Comment créer un compte ?

Depuis la page d’accueil, cliquez sur Créer un compte. Renseignez votre adresse e-mail ainsi qu’un mot de passe sécurisé, puis validez votre inscription. Après la création du compte, BastCompta prépare automatiquement votre espace personnel.

8. Comment se connecter ?

Cliquez sur Se connecter, saisissez votre adresse e-mail et votre mot de passe puis validez. Si les informations sont correctes, vous accédez immédiatement à votre tableau de bord.

9. J’ai oublié mon mot de passe

Depuis l’écran de connexion, utilisez l’option Mot de passe oublié. Un e-mail de réinitialisation sera envoyé à l’adresse associée à votre compte.

10. Que faire lors de la première connexion ?

Il est conseillé de : - compléter les informations de votre entreprise ; - vérifier vos paramètres ; - découvrir les différents modules ; - configurer Google Drive si vous souhaitez synchroniser vos données ; - effectuer une première sauvegarde une fois vos informations encodées.

11. Informations de l’entreprise

Les paramètres de l’entreprise permettent notamment de renseigner : - le nom de l’entreprise ; - l’adresse ; - les coordonnées ; - le numéro d’entreprise ; - le numéro de TVA ; - les informations utiles apparaissant sur vos documents. Ces informations sont utilisées dans plusieurs modules.

12. Comment naviguer dans BastCompta ?

Le menu principal donne accès aux différents modules. Chaque module possède ses propres onglets et outils. Vous pouvez passer d’un module à l’autre sans perdre vos données.

13. Que signifie l’état « À vérifier » ?

Certaines informations peuvent être signalées comme nécessitant une vérification. Cela permet d’attirer votre attention avant une impression, une exportation ou une déclaration. Il est conseillé de contrôler ces éléments avant de poursuivre.

14. Comment se déconnecter ?

Utilisez le bouton Déconnexion disponible dans l’application. Votre session est fermée en toute sécurité. Pensez à vous déconnecter lorsque vous utilisez un ordinateur partagé afin de protéger vos données.

Abonnements

15. Quelles sont les fonctionnalités gratuites ?

BastCompta est disponible gratuitement avec un ensemble de fonctionnalités accessibles sans abonnement. La version gratuite permet notamment de découvrir l’application, de créer votre compte, d’utiliser les fonctions disponibles sans pack actif et de tester l’interface avant de souscrire un abonnement. Certaines fonctionnalités avancées sont réservées aux différents packs.

16. Comment fonctionne l’essai gratuit de 30 jours ?

Lors de votre première activation, vous pouvez bénéficier d’un essai gratuit de 30 jours. Pendant cette période, vous profitez de tous les packs sans engagement, y compris du module Personnel complet. À la fin de l’essai, vous pouvez continuer avec la version gratuite ou souscrire un abonnement.

17. Qu’est-ce que le Pack Comptabilité ?

Le Pack Comptabilité donne accès aux outils dédiés à la préparation de votre comptabilité. Selon les évolutions de BastCompta, il comprend notamment les fonctions liées à la comptabilité, à la préparation de la TVA, à l’IPP ainsi qu’aux fonctionnalités prévues pour ce pack.

18. Qu’est-ce que le Pack Suivi client ?

Le Pack Suivi client est destiné aux utilisateurs souhaitant gérer la relation client et le personnel. Il donne accès au CRM, au suivi des clients et chantiers ainsi qu’au module Personnel complet : travailleurs, salaires, prestations, congés, maladies et absences, primes et avantages, documents, formations et matériel.

19. Qu’est-ce que Premium ?

Premium regroupe l’ensemble des fonctionnalités disponibles dans BastCompta. Il inclut notamment le Pack Comptabilité, le Pack Suivi client et le module Personnel complet, ainsi que les futures fonctionnalités incluses dans l’abonnement Premium.

20. Quelles durées d’abonnement sont proposées ?

Les abonnements peuvent être proposés en plusieurs durées (mensuelle, trimestrielle ou annuelle selon le pack). Les tarifs sont consultables directement dans l’onglet Tarifs / Abonnements de BastCompta.

21. Comment demander l’activation d’un abonnement ?

Depuis le menu des abonnements : - choisissez le pack souhaité ; - sélectionnez la durée ; - suivez les indications de paiement. Une fois le paiement validé, votre abonnement est activé.

22. Comment connaître la durée restante ?

La page des abonnements affiche : - votre abonnement actif ; - sa date de fin ; - le temps restant avant son expiration. Vous pouvez ainsi anticiper son renouvellement.

23. Que se passe-t-il lorsqu’un abonnement expire ?

Lorsque votre abonnement arrive à échéance, les fonctionnalités liées à celui-ci deviennent indisponibles. Vos données ne sont toutefois pas supprimées. Vous pourrez de nouveau y accéder après le renouvellement de votre abonnement.

24. Mes données sont-elles conservées ?

Oui. Même si votre essai gratuit ou votre abonnement expire, BastCompta conserve vos données. Vous gardez donc votre historique et pourrez le retrouver lors de la réactivation de votre abonnement. Il est néanmoins recommandé d’effectuer régulièrement une sauvegarde ZIP ainsi qu’une synchronisation Google Drive lorsque cette fonctionnalité est utilisée.

Que permet le module Personnel ?

Il centralise les fiches des ouvriers et employés, salaires et coûts, prestations, congés, maladies et autres absences, primes et avantages, documents, formations et matériel attribué. Google Drive reste disponible gratuitement ; l’accès au module Personnel dépend toutefois de l’essai de 30 jours, du Pack Suivi client ou de Premium.
